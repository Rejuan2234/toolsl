# Toolsl — Free Online Tools

**Toolsl** is a collection of useful online tools designed to make everyday tasks easier. The website brings calculators, generators, and other helpful utilities together in one place.

🌐 **Live Website:** https://toolsl.netlify.app/

## ✨ Features

* 🧮 Age Calculator
* 🎓 CGPA Calculator
* 💰 Zakat Calculator
* 🔐 Password Generator
* 👤 Username Generator
* 🔤 Random String Generator
* 📱 QR Code Generator
* 🌐 IP Address Checker
* 🎙️ Voice to Text
* 🖼️ Image to Text
* 🚀 Internet Speed Test
* 📝 Facebook Caption Generator
* 📧 Temporary Email Tools and Guides

*Some features may depend on external services or APIs.*

## 🚀 Getting Started

You can visit the live website directly:

**https://toolsl.netlify.app/**

To run the project locally:

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Configure any required services or API settings if applicable.

## 💻 Installation

Clone the repository using Git:

```bash
git clone https://github.com/Rejuan2234/toolsl.git
```

Navigate to the project folder:

```bash
cd toolsl
```

Open the folder in Visual Studio Code and launch `index.html` in your browser.
